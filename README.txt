NABUTO PLATFORM V4 — NEXT.JS + TAILWIND

Bu sürüm profesyonel Next.js App Router, TypeScript ve Tailwind CSS altyapısı kullanır.

GITHUB'A YÜKLEME:
1. ZIP'i bilgisayarında ayıkla.
2. GitHub'da Nabuto-web deposunu aç.
3. Depodaki eski site dosyalarını kaldır.
4. Bu klasörün içindeki TÜM dosya ve klasörleri yükle.
5. Commit changes düğmesine bas.
6. Vercel otomatik kurulum yapacaktır. İlk yayın birkaç dakika sürebilir.

ÖNEMLİ:
- ZIP dosyasının kendisini yükleme.
- app, components ve public klasörleri mutlaka yüklenmeli.
- package.json kök dizinde bulunmalı.
- Vercel ayarlarında Framework Preset otomatik olarak Next.js görünmelidir.
- Node.js sürümü en az 20.9 olmalıdır.

YEREL ÇALIŞTIRMA:
npm install
npm run dev
